# BankS

This repository hosts the deposit purchase system implementation.

## Proxy Helper

To configure the git network proxy (default port 7890) run:

```bash
scripts/configure_git_proxy.sh enable
```

To disable the proxy configuration run:

```bash
scripts/configure_git_proxy.sh disable
```

You can inspect the current proxy configuration via:

```bash
scripts/configure_git_proxy.sh status
```
